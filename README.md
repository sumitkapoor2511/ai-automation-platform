# AI-Native Full-Stack & Autonomous Agent Platform
An enterprise automation ecosystem using FastAPI, PostgreSQL, n8n AI Agents (Google Gemini), and Nginx via Docker Compose. See repository for full ASCII architecture diagram and CRUD agent capabilities.
## Quick Start (< 60 Seconds)
1. Copy `.env.example` to `.env` and fill in secrets: `cp .env.example .env`
2. Launch the stack: `docker compose up -d --build`
3. Access FastAPI Swagger UI at `http://localhost/docs` and n8n at `http://localhost:5678`.
